# tesys-data

Scripts y catálogos chicos para preparar y cargar los datos de comercio exterior en la base de Tesys.

- `scripts/` — catálogos, importadores, reportes y validación.
- `sql/catalogos/` y `data/catalogos/` — catálogos pequeños (aduanas, países, divisas, unidades, destinaciones, estados).
- `sql/queries/` — consultas de reporte.

Los datos (archivos originales, SQL generados, volcados, exportaciones) no se versionan: ver `.gitignore`.
